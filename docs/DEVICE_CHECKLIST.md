# 真机验证清单

只有单元测试、还没上过真机的功能，按下面的顺序逐项验证。
已经上过真机的（登录、邮件、背包出售、签到、好友、聊天、广播、在线礼包、好友赠礼）见 `testdata/captures/device-session-2026-10-19/NOTES.md`。

## 没有手机时先自测

服务起来后跑一遍机器人，它按真实协议走完主线，每步打印 ok / FAIL：

```sh
go run ./cmd/bot -user botplayer1
```

全部 ok 说明服务进程、配置、数据库迁移没有问题；它不能代替真机，因为客户端界面的反应只能在手机上看到。

## 先做这条主线（约 10 分钟）

一个新号，按顺序走完。**任何一步卡住就停下，把现象告诉我**，后面的项不用再做。

| 步骤 | 操作 | 预期 |
|------|------|------|
| 1 | 新建角色，进主城，打开“英雄” | 有 1 个起始英雄（男角色修罗、女角色娜美），属性和技能有数值 |
| 2 | 点战役的“挑战” | 先出现**布阵面板**，起始英雄已在阵上 |
| 3 | 点布阵面板里的“出战” | **不卡在加载**，直接弹出胜利结算（带奖励） |
| 4 | 关闭结算 | 关卡进度 +1，主城建筑状态不变或更新 |
| 5 | 再挑战几次 | 一关关推进；换章节时有提示；经验够了弹出升级窗口 |
| 6 | 战役右上角的宝箱 | 等几分钟后能领挂机收益 |

第 3 步是整个方向的分水岭：服务器没有战斗数据，只发结算。**如果这一步卡住，请把 `gateway.log` 里那一段发给我**，我会改成最小的战斗数据下发。

## 准备

召唤界面在真机上点“召唤”没反应时，可以用 `go run ./cmd/granthero -config configs/lan.yaml -rid <角色> -hero <bid:星级> ...` 直接发英雄（见 `docs/CAMPAIGN_PLAN.md` 的 2026-10-20 一节）。

1. 启动服务：`make dev`（或分别启动三个服务），配置里设 `log_dir: data/logs`，日志在 `data/logs/gateway.log`。
2. 建议用新账号，保持 1 级，这样等级变化看得出来。
3. 用邮件给资源（角色 id 在日志或后台查）：

```sh
# 抽卡、养成、商店、战役都用得上的一批资源
go run ./cmd/mailtool -rid 1 -subject 测试资源 -content 测试 \
  -asset gold=2000 -asset hero_exp=500000 -asset coin=2000000 -asset charge_bi=100000 \
  -item 10401=20 -item 10003=20 -item 10004=5 -item 10001=1000 \
  -item 40101=2 -item 40201=1
```

   客户端里点邮件 → 一键领取，资源栏和背包应立刻刷新。
4. 出问题时在日志里搜 `no handler`，那是客户端发了、服务器没处理的指令编号：

```sh
grep "no handler" data/logs/gateway.log | sort | uniq -c
```

## 逐项验证

每一项：操作 → 预期 →（记）要留意什么。

### 一、战役的收入
- **挂机收益**：宝箱领取。预期：弹窗显示时间和奖励，宝箱清空。
- **快速作战**：通关 10020 关后开放。第一次免费，第二、三次扣钻石（100、200）。预期：弹出奖励窗口，次数文字更新。
- **扫荡**：对已通关的关卡点扫荡（一次最多 5 次，一天 10 次）。前 3 次免费，之后每次扣 1 张扫荡券。
- **里程碑奖励**：战役里的章节/关卡奖励宝箱。第 1 号奖励（40 亿钻石）会被拒绝，提示“奖励配置异常”，这是预期。

### 二、角色升级
- 预期：弹出升级窗口，列出每一级的奖励（钻石），资源栏等级和经验条更新。
- 记：窗口有没有弹、奖励数字对不对、经验条是否正常。

### 三、英雄
- **升级**：选英雄 → 升级。消耗英雄经验和金币。预期：等级 +1，属性变大。
- **突破**：到当前等级上限后突破（消耗金币和突破卡）。突破面板里能看到突破后的属性预览。
- 记：属性数字、战力是否合理，按钮可用状态是否对。

### 四、布阵与装备
- **布阵**：调整位置、换阵法后保存，再打开仍是保存的样子。
- **装备**：英雄详情里穿戴邮件发的武器、护甲。预期：攻击/生命增加，卸下后恢复，换装备时旧的回到装备背包。

### 五、招募
- 基础召唤第一次显示“免费”。免费单抽；用召唤券（物品 10401）单抽、十连；高级召唤（钻石或道具）。
- 预期：弹出抽卡结果，新英雄进入英雄列表，积分增加。
- 记：结果动画和英雄展示是否正常；材料不够时界面有没有卡住（服务器此时不回包）。

### 六、升星
- 起始英雄 10401（修罗）是 4 星，升 5 星需要再有 2 个 4 星的 10401，以及阵营英雄（4 星 5 个、3 星 4 个）。要先抽卡攒材料。
- 按提示选材料，点升星。预期：被吃掉的英雄消失，星级 +1，装备退回背包。

### 七、背包
- **开礼包**：背包里选“每日签到礼包”，使用。预期：拿到钻石、突破卡等。
- **合成**：只有两个配方（10428×50 → 10421，10429×30 → 10441）。

### 八、任务、成就、商店
- **每日任务**：12 个任务，登录任务应已完成，点领取拿钻石和活跃度。召唤、赠送友情点会推进对应任务。
- **成就**：199 个。能完成的只有：角色等级、好友数量、赠送友情点次数、战力（基本达不到）。领取一个，预期奖励到账、状态变“已领取”。
- **道具商店**：用代金券（`charge_bi`）购买。预期：购买成功，资源和背包刷新；有限购的商品买第二次会被拒。

### 九、排行榜
- “剧情进度”和“战力”两个榜有数据，其余为空。

## 出问题时发给我的东西

- 现象描述和截图。
- `data/logs/gateway.log` 里出问题那段时间的行（包括 `no handler` 的指令编号）。
- 能抓原服务器的包更好，优先级见 `docs/OPEN_QUESTIONS.md` 末尾。

## 已知的预期行为（不是 bug）

- 战役一律判胜，没有战斗动画。
- 失败的召唤、购买等，有的会没有提示（服务器不回包或只回文字）。
- 竞技场、公会、爬塔等玩法都是空界面。
- 装备只能靠邮件、礼包、商店获得（没有战斗掉落）。
