## 主项目构建与入口

当前默认后台由 Go 提供，无需 Vite 服务：根目录执行 `nvm use 22.23.4`、`make build`，再用 `./bin/admin -config <配置>` 启动；生产嵌入资源快照随源码入库，干净检出可直接 Go 构建，不会回退旧页。前端改动后用构建脚本更新快照；dist/node_modules/bin 不入库。真实本地网关 + TCP 邮件、公告、封禁踢线与离线恢复已验证，真机界面未验。完整步骤、安全头、证据和边界见 [Go 接入与联调说明](../../docs/ADMIN_UI_INTEGRATION.md)。

隔离试用地址默认为 `http://127.0.0.1:19080/#/login`，测试账号在启动脚本打印的目录中 `fixture.json`（0600）。下述第二至第四阶段验证保留为迁移记录，Vite 开发/预览属于可选工具，旧链接配置已移除。

## 已迁移功能与权限

| 功能                                                  | viewer              | operator       | superadmin |
| ----------------------------------------------------- | ------------------- | -------------- | ---------- |
| 概览、区服列表、角色搜索/筛选/分页及详情、环境页      | 可读                | 可读           | 可读       |
| 概览运营广播                                          | 隐藏并拒绝 API 写入 | 可操作         | 可操作     |
| 区服新建、编辑、维护/开放、删除                       | 隐藏并拒绝写入      | 隐藏并拒绝写入 | 可操作     |
| 角色封禁/解封/踢线、等级/VIP、资源/英雄/皮肤/外观发放 | 隐藏并拒绝写入      | 可操作         | 可操作     |

菜单与直接访问路由均按 Go 权限过滤：审计、备份、管理员仅超级管理员可见，其余业务页三档可读，写按钮按权限区分。所有业务操作均可在新版完成；旧后台保留用于对照。角色页“发邮件”会进入新版 `/mail?to=<角色ID>&srv_id=<区服>`，自动带入角色及区服，不再依赖旧后台邮件入口。

- 登录：`POST /api/login`；刷新、每次路由跳转、窗口重新聚焦和可见页每 60 秒调用 `GET /api/me` 验证身份，写操作前再次验证。账号停用、降权、改密由服务端实时判定。
- 凭证只放 sessionStorage（不可用时仅内存），使用 `Authorization: Bearer`；恢复时不信任缓存管理员/角色，必须重新请求 `/me`。HTTP 状态码判断失败，读取 Go `error`，处理 401/403/429、超时和网络错误，不使用上游 code/msg/data 或 x-access-token。
- 401 和本机已知过期清除会话并回登录；身份复核失败时停止显示受保护页面。退出清理凭证、身份、权限、标签页和页面缓存。Go 没有 logout 撤销接口，本地退出不等于撤销已签发 JWT，服务端过期/改密/停用机制保持原样。
- 角色页使用服务端 `limit/offset/items/total` 分页（25/50/100），支持角色名、账号名、角色 ID、区服筛选；详情显示在线未知/离线/在线、资源与物品账本。
- 发放沿用上限和服务端校验：等级 1–200、VIP 0–30、资源 1–20 项/每项 1–10 亿、英雄总数 1–20/星级随元数据、皮肤/外观 0–3650 天。货币使用元数据，物品可按中文名/ID 搜索，英雄/皮肤/外观保留名称选择。
- 危险写操作有确认；写入期间防重复提交，任何迟到的旧会话响应不能覆盖或清除新会话。
- 网关不可用时在线人数显示“—/暂不可用”，角色在线显示“未知”。广播/踢线 502 明确报错。资源/英雄/皮肤写入成功但 `push_error` 或 `refreshed:null` 时提示“已保存但未通知”；外观提示重新打开面板读取。封禁、等级/VIP 接口不返回踢线结果，因此只确认数据保存和请求发出，不声称客户端已断开。

页面与角色详情按路由/打开时加载，业务页面不使用 KeepAlive、不在隐藏页轮询统计；通用缓存上限 8。角色筛选和翻页共用一个标签页，避免每次查询创建新缓存。

## 第三阶段：邮件、充值和活动

新增入口：`/#/mail`、`/#/pay`、`/#/activities`。开发版在 15173，生产预览在 14173。三个页面均按路由懒加载、不缓存敏感页面，不对隐藏页持续请求数据。所有提交继续使用真实 Go API，没有引入远程 Mock 或支付网关，也没有修改 Go 的路由、存储和鉴权契约。

| 操作                                                    | viewer   | operator | superadmin |
| ------------------------------------------------------- | -------- | -------- | ---------- |
| 查看邮件历史、充值配置/订单、活动列表                   | 可读     | 可读     | 可读       |
| 发送邮件、创建/编辑/复制/删除活动                       | 不可操作 | 可操作   | 可操作     |
| 上传/清除收款码、保存支付说明、补单、确认到账、取消订单 | 不可操作 | 不可操作 | 可操作     |

邮件保留定向（最多 500 个角色）、按区服广播、全服广播，主题/正文/发件人/类型 1 或 3、0–365 天或指定失效时间、最多 8 个货币/物品附件。共享物品组件按中文名/编号搜索，角色可按名称/账号/ID 定位；角色页快捷入口直接预填新版邮件。历史使用服务端 limit/offset/items/total，展示已建立收件关系数和附件领取数，可查看完整正文和附件。广播按符合条件角色查看邮件时才逐步建立收件关系，不能把当前收件数解释为全服人数。邮件保存和网关推送分开反馈。

充值保留两渠道收款码（PNG/JPEG/WebP，最多 600 KB）、支付说明（300 字）、订单状态筛选、金额、角色/区服、商品、处理人和备注。订单接口仅返回指定状态最近 N 笔，支持 25/50/100/200 条选择，**没有 total/offset，不伪造总数或翻页**。手工补单可以搜索角色或输入角色 ID，只选择 `/pay/products` 返回的可发货商品；额外购买资格限制仍由 Go 校验。不支持的商品不可在前端确认。确认/取消/立即发货均需复核确认；重复确认/取消由真实服务端返回 409。仅创建待付款订单时，原 Go 接口不保存补单备注；立即确认的备注按原契约记录。

活动保留按区服列表（包含全服活动）、关闭/未开始/进行中/已结束状态和增改复制删除。支持活动号、页签、标题/副标题、面板类型、排序、图标/横幅/提示文字、起止时间、每日重置、目标及奖励。目标格式为 `编号 | 说明 | 事件 | 目标数 | 奖励编号:数量,奖励编号:数量`，会检查唯一 ID、数量、条数和时间；可搜索奖励名称/ID 并生成目标示例。复制保留原活动号、页签、时间和全部 spec，作为新记录创建。编辑保留表单外 spec 字段和目标扩展，不修改源对象；真正不被当前 Go 识别的字段仍返回 422，前端不会为了保存成功而自动删字段。已有开始时间为 0 的活动可留空保持不限制开始时间。

本批使用统一数字输入组件，修复上游数字控件在父表单禁用/更新后显示值或 ARIA 与实际提交值不同步的问题。发送与补单在权限复核、确认弹窗和请求全过程加锁，防重复点击。网络中断、超时、非 JSON 成功响应或 5xx 可能发生在服务端写入之后；此时不会自动重试，必须先刷新核对历史并明确解除锁定、重新填写。支付“已发货”与“客户端已刷新”分开描述；网关缺席不伪称在线推送完成。

### 共享行为与契约边界

- `src/domain/management.ts` 维护新增 10 页权限清单、请求映射及纯校验；`useCollection` 处理真实列表、分页与迟到响应；`CollectionPage`/`RecordTable` 统一加载、空状态、错误和翻页。原六页保留现有实现。
- 沿用 `useCommand` 提交锁，覆盖身份复核、确认和请求。本地表单校验错误不会被当作“提交结果不明”；网络超时、5xx、无法解析的成功响应对创建/回复/改密等非幂等操作禁止直接重试，需先核对历史或重新登录。工单结果不明时保持原工单，避免核对另一工单后重复回复。
- 密码按 Go/bcrypt 的 UTF-8 **8–72 字节**校验；兑换码备注最多 200 字节，封禁原因和正文按 Unicode 字符计数。数量沿用安全整数和原上限；复用原生数字输入组件，显示与提交一致。日期使用浏览器本地时区输入/显示并提交 Unix 秒；空开始时间保持 0，空结束时间表示不结束，不偷偷转换为当前时间。
- **会话语义保持 Go 原样**：降权立即更新已有 token 的权限，越权 API 403，允许的读取仍可用；停用期间 API 401 并清理本地会话；重新启用且未改密时，尚未过期的旧 token 可能再次可用；密码更改/重置通过密码戳使所有旧 token 失效。不会虚构 Go 没有的永久注销/撤销接口。身份复核时若当前页面权限被收回，清除标签/缓存并跳到 403；401 则跳登录。
- 公告保存/删除落库成功但网关未通知时显示警告，不误报保存失败；网关返回在线通知数也不等同真机已接收。游戏账号封禁接口不返回踢线结果，页面只确认封禁数据；公会解散对在线成员的画面在重新登录后更新。
- 工单只有最近 100 条，举报只有最近 200 条，兑换码为全量列表；不添加假 total/offset。公会仍受 Go 接口每区服最多读取 1000 个候选公会的现有限制。审计无服务端筛选器，备份无下载/恢复 API，均保留原契约。
