# ONE PIECE · 索隆环形抽卡 Demo

独立本地 H5 演示。按照用户提供的截图与视频，使用紫色索隆包面、蓝紫到白的竖屏背景、十包环形立体旋转与地面倒影。高清包面底图与卡面为 ImageGen 生成，包装标题使用矢量文字。没有接入真实抽卡、账号、支付或游戏资产。

## 运行

直接用浏览器打开 `standalone.html` 即可体验。这个单文件已内嵌脚本、样式和全部使用中的图片，刷新或离线打开都不依赖预览服务，也不需要另带 assets 文件夹。

修改源码后执行 `npm run build` 重新生成单文件。`index.html` 保留为开发入口：

无需安装依赖。需要 Node.js 18 或更新版本：

```sh
cd demos/card-summon
npm run dev
```

访问 http://127.0.0.1:4178 。用 `PORT=4180 npm run dev` 可更换端口。也可以直接用浏览器打开 `index.html`（浏览器的本地文件限制可能影响部分能力，推荐 HTTP 预览）。

手机端在 780px 及以下宽度启用独立的 `mobile.css`：精简标题、按可用高度分配动画舞台、底部紧凑操作区，并预留屏幕安全区。卡包和揭晓卡片按可用宽高等比缩放，保留原十连旋转与自动拆包流程；短横屏允许页面滚动，十连结果每行五张、共两行，小屏可滚动查看。桌面样式文件保持原格式。本地 `127.0.0.1` 入口只供运行服务的电脑访问，手机真机访问需另行配置局域网入口或 HTTPS 静态托管。

`game-frame.css` 在手机布局之后加载，参照原游戏召唤页收紧外框：薄顶栏、满宽舞台、舞台下方的标题横幅与连续底部操作面板。保留紫色索隆主题、全部现有文案、卡面与交互，只调整手机布局和装饰，不影响桌面布局与动画层。

电脑查看手机效果可打开 `mobile-preview.html`，它以 390×844 的内嵌视口加载同目录的 `standalone.html`，可直接操作；实际手机访问使用正常入口即可。

## 交互

- 默认十包：10 个独立卡包绕竖直轴排成一圈，每包相差 36°。前排正面放大，左右侧转裁切，后排背面被前排遮挡。
- 自动每秒转动 12°，30 秒一周；支持拖动环形、暂停/继续，以及「正面视角」一键暂停并对齐正面。
- 十个包固定在圆环内，由父节点的一段原生 transform 动画整体旋转，正常自动环绕没有 JavaScript 逐帧循环。倒影使用固定的正背两面，不在旋转途中切换图片。
- 十包开启时，环形收拢为有纵深的堆叠，按 155ms 间隔逐包自动切封、撕开，再汇成牌堆依次翻面；点击卡片继续揭晓，最后汇总十张结果。
- 单包开启时自动聚焦、切封、撕开并揭晓卡片；揭晓后停留在大卡展示，直接解锁「再次开启」，无需再点击卡片进入汇总页。单包跳过动画同样直达大卡展示。
- 「跳过动画」或 Escape 直接展示已确定的结果，十连保留汇总页。「重播上次结果」保持卡片序号和顺序，不重新抽取。
- 单包揭晓页和十连汇总页均有「返回卡包」，返回初始卡包展示并保留上次结果，可继续重播或再次开启。
- 本版十张卡使用同一张索隆插画配独立收藏序号，仅演示，不代表十种不同立绘或真实抽取概率。
- 默认静音，可开启 Web Audio 合成音效；系统减少动态效果设置会停用自动旋转。

## 文件与素材来源

- `index.html` / `app.js`：界面、环形位置计算、旋转/拖动、开包状态、跳过与重播。
- `styles.css`：基础布局和单包动画。
- `multi-pack.css`：独立包体撕封和双面翻卡。
- `carousel.css`：十包环形空间位置、包装比例、背面朝向、倒影、堆叠与旋转控制。
- `reference-theme.css`：与参考图相近的蓝紫到白竖屏舞台。
- `mobile.css`：手机视口布局、安全区、触控尺寸和小屏卡片/结果列表覆盖样式。
- `game-frame.css`：手机游戏外框、标题横幅与底部操作面板。
- `assets/zoro-reference.png`：用户提供的截图，原文件保持不变。
- `assets/zoro-pack-art-hd.png`：参照原包面构图重绘的高清底图，实际 961×1637，原截图有效包面约 310×530；不含文字或鼠标光标。内置 ImageGen 完整提示词见 `assets/zoro-pack-hd-prompt.txt`。
- `assets/zoro-pack-front-hd.svg`：1024×1750 画布，内嵌高清底图，叠加原生 SVG 包装标题、小标和压纹边。文字不再随截图模糊。
- `assets/zoro-pack-back-hd.svg`：同尺寸的紫色矢量包装背面，标有 DEMO。
- `build-pack-textures.mjs`：生成上述高清正背面；`npm run build` 先更新包面，再生成自包含 `standalone.html`。
- `assets/zoro-pack-front.svg`、`assets/zoro-pack-back.svg`：旧截图/视频裁切素材，保留用于对照，当前演示不再引用。
- `assets/zoro-card-art.png`：新生成索隆插画，1024×1536；内置 ImageGen 的完整提示词见 `assets/zoro-art-prompt.txt`。
- `assets/zoro-card-back.svg`：紫色三刀流主题卡背。
- 早期航海主题资产保留在 assets 中，但当前场景不再引用。

十个包拥有真实 CSS 3D 前后深度和独立正背面；关闭矩形侧片与额外竖向描边，避免出现脱离包身的亮线。封口使用预设分片动画，并非实时布料模拟。当前包面是高清重绘与矢量排版，非原厂高清印刷素材；环形比例、背景和倒影按参考重建，不宣称恢复了原动画工程。十个包、封条、撕片与倒影共用一套预解码纹理，保留上一版的动画优化。

## 替换素材和接服务端

1. 包面底图替换 `zoro-pack-art-hd.png`，排版修改 `build-pack-textures.mjs`，然后运行 `npm run build`。卡面替换 `zoro-card-art.png`。保持包装约 230:393、卡面约 2:3 的比例；如改资源路径，同步 HTML、`app.js` 和 `build.mjs`。
2. 在 `app.js` 的 `CARDS` 中配置名称、品质、卡面 ID；`cardImage()` 当前统一指向索隆插画，可改为按 ID 映射。
3. 保留「结果先确定，动画只展示」的边界。将 `createDemoResult` 替换为真实结果适配层，服务器确认后再调用 `start(resultList)`。不要在每张卡片的动画回调里发起抽取。
4. 现有服务端 `23201.partner_bids` 的 `partner_bid / init_star` 可映射卡面；还需实现浏览器登录、二进制协议编解码、资源映射和错误/断线恢复。
5. 网关已有 WebSocket 能力，但此 demo 不建立任何游戏连接。正式接入前要补齐部分召唤失败静默分支，防止等待结果时卡住。

预加载完成前禁用开包，动画运行时锁定重复抽取。跳过会使旧时间轴失效，避免旧回调覆盖新结果；结果在内存中保存，刷新页面会清除。

HTTP 开发预览会将验证通过的四种素材保留为页面内的 Blob URL，卡面、结果列表和倒影共用这些资源。已打开的页面在预览服务停止后仍可开包、翻牌和重播；重新加载开发入口仍需运行服务。离线或长期保存请使用 `standalone.html`。

旋转优化：一个 Web Animations transform 动画驱动整圈，十个子包只在初始化、调整尺寸与收拢交接时设置位置。暂停、拖动、后台及系统减少动态效果通过暂停/定位同一个动画实现。封闭包装内的卡片和重复封条在环绕时不参与绘制。收拢前将当前角度转换成各包世界姿态，接回原有拆封动画。

过渡优化：移除了不可见粒子的绘制和相关布局读取；素材在开包前完成解码。收拢全程固定布局位置，仅通过 transform 移动，850ms 收拢完成后衔接拆封；翻牌使用连续曲线。

## 检查

```sh
npm run check
```

人工检查：十个环形位置、自动角度变化、暂停/正面对齐、拖动、前后面及倒影、单抽/十连自动拆封、逐包切封与翻牌、各阶段跳过及重播一致性、窄屏与键盘操作。

可用 `/?profile` 开启本地帧间隔与包体样式写入计数，阶段切换时写入隐藏的 `#frameStats`，正常演示不启动该采样循环。其帧间隔数据反映当前浏览器的 RAF 节奏，不能代表合成层的实际呈现帧率，也不能作为手机实际帧率的保证。
